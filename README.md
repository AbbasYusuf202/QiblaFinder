## step 1:

- Use the dev kit inbuilt LSM303AGR and 4 LEDS to point to North, south, east and west.

## step 2:

- Obtain GNSS receiver and along with inbuilt LSM303AGR use 4 LEDS to point to the qibla which is the kaaba in Mecca.

## step 3:

- Make a custom pcb with a gnss receiver, some method of powering, LSM303AGR and a circular LED array to get a more accurate qibla direction.



***extra info:***

The devkit is the MB1115D 32F411EDISCOVERY board

The steps will be described in more detail in the readme for each step.
